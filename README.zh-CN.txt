HP2 驾驶仪表 1.7.0 · Windows x64
将 ZIP 解压到游戏根目录。双击 Play-HP2-ShiftLight.cmd 同时启动游戏和仪表，也可以直接运行 HP2-ShiftLight.exe 连接本机正在运行的游戏。体积云 1.4.11 启动时会一并打开已安装的仪表。主表在菜单里显示等待状态，开始驾驶后显示实时读数。主副表的整个表面都允许鼠标点击穿透，游戏保留键盘焦点。退出游戏后，两块表会一起关闭。

主表盘
主表盘位于游戏画面底部中央，显示车速、转速、换挡灯、当前与建议挡位。双轴 G 力按乘员体感显示，加速向后、制动向前、左转向右、右转向左。圆点与数值使用最近 0.5 秒游戏时间的加权平均。三圈刻度依次为 1、2、3 g。超过 3 g 时，圆点停在外圈，横纵数值继续显示实测平均值。

升降挡
每辆车按游戏中的发动机扭矩曲线及齿比计算升挡点。在同一车速下，下一挡的全油门轮上驱动力追上当前挡时升挡。如果当前挡一直更强，目标取在游戏断油前 75 RPM。
加速接近换挡点时，灯条按绿、黄、红依次点亮。前九灯从目标转速的 82% 至 98% 逐颗亮起。全排闪红提示升挡。转速持续爬升时，闪灯最多提前 120 毫秒，提前量上限 180 RPM。松油、换挡、停车或进入最高挡时，升挡灯熄灭。
绿色向下箭头提示降挡。松油或制动时仍会提示，前提是降挡在当前和预计接合车速下都能增加可用驱动力，并为红线留出余量。在顺序手动模式中，可连续降至建议挡。
入挡功率显示离合器接合后预计可用的全油门功率，占本车发动机峰值功率的百分比。降挡提示使用建议的低挡，其余时候显示相邻高挡的估算。没有可预测的挡位时显示短横线。

HP 直升机副表盘
进入有警力的车手赛事时自动出现，离开时收起。副表盘位于主表盘右侧，右侧空间不足时放在左侧。副表盘跟踪第一位本地玩家。直升机决策前显示候选攻击或“攻击待判定”；锁定本车并选好攻击后，显示导弹、火药桶、双排火药桶或钉刺带。攻击取消或目标改变会清除预警。玩家担任警员时隐藏副表盘。

源码位于 HP2-ShiftLight-Source。可用 .NET Framework 4.x 的 64 位 C# 工具链运行 build.cmd 重建。
